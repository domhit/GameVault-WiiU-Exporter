# GameVault Wii U Exporter

Read-only inventory exporter for **Nintendo Wii U**, **vWii NAND**, and Wii games scanned by **USB Loader GX**. The generated JSON files are designed for import into GameVault.

## Features

- Wii U base games, updates and DLC via MCP.
- Wii U metadata from installed `meta.xml`: localized title, Product Code, publisher, region and additional platform metadata.
- vWii NAND title inventory through read-only IOSUHAX/FSA access to SLCCMPT.
- Read-only Wii TMD decoding for title ID, title version, IOS/system version, group, region, access rights, content count and boot index.
- Wii USB inventory from USB Loader GX `cache/WII.cache` on SD, including 6-character Game ID, cached title, `usb1:/wbfs/...` path and WBFS/ISO format.
- Optional PlayCount import from USB Loader GX `GXGameStatistics.cfg`.
- ProcUI-aware `WHBLogConsole`; A and HOME return safely to the Wii U Menu.
- No Wii U, vWii NAND, ticket, TMD, IOS, channel or game content is modified.

## Output files

The exporter writes to:

`/vol/external01/wiiu/apps/GameVault-WiiU-Exporter/`

Over FTP this is typically:

`/fs/vol/external01/wiiu/apps/GameVault-WiiU-Exporter/`

Files:

- `installed_titles.json` — Wii U GAME / UPDATE / DLC inventory, schema 1.
- `vwii_titles.json` — vWii NAND title/TMD inventory.
- `wii_usbloadergx.json` — Wii games from USB Loader GX `WII.cache`.

The obsolete raw USB/UStealth diagnostic exports from v0.2 development builds are not generated by the v0.2.0 release.

## USB Loader GX cache freshness

`wii_usbloadergx.json` reflects the **most recent USB Loader GX cache**, not a direct scan of the UStealth USB disk by this exporter.

**After adding, removing, renaming or replacing Wii games:**

1. Start USB Loader GX in vWii.
2. Let its game list finish loading so `WII.cache` is refreshed.
3. Exit USB Loader GX.
4. Run GameVault Wii U Exporter.

The exporter expects the tested SD layout:

- `/vol/external01/apps/usbloader_gx/cache/WII.cache`
- `/vol/external01/apps/usbloader_gx/GXGameStatistics.cfg` (optional)

`WII.cache` is treated as the authoritative list of games last scanned by USB Loader GX. Banner-cache files are not treated as proof that a game is still present.

## Installation

1. Create `sd:/wiiu/apps/GameVault-WiiU-Exporter/` if it does not already exist.
2. Copy `GameVault-WiiU-Exporter.wuhb` into that directory.
3. Launch it from Aroma.
4. Wait for the export summary.
5. Press A or HOME to return to the Wii U Menu.

vWii inventory requires a compatible Mocha/IOSUHAX environment. USB Loader GX is only required for the Wii USB cache source.

## Build

GitHub Actions builds with:

- `devkitpro/devkitppc`
- `wiiu-env/libmocha`
- `wiiu-env/libiosuhax`

A push to `main` builds an artifact. A stable `v*` tag builds and publishes `GameVault-WiiU-Exporter.wuhb` as a GitHub Release asset.
